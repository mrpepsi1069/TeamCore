# TeamCore

Discord bot (`/bot`) + web dashboard (`/frontend`, `/backend`) for league and community management, sharing one MongoDB Atlas database.

* **Docs:** [Architecture & security](docs/ARCHITECTURE.md) · [Setup](docs/SETUP.md) · [Deployment](docs/DEPLOYMENT.md) · [Feature coverage](docs/COVERAGE.md) · [Bot commands](docs/BOT.md)
* **Quick start:** see `docs/SETUP.md` → section 4.
* **Never commit `.env`** (it is in `.gitignore`). Secrets live only in your hosts' environment variables.
